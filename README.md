# শালিখা সার্বজনীন দুর্গামন্দির — Mahalaya Website

GitHub Pages-এর জন্য তৈরি static website।

## ফাইল
- `index.html` — মূল ওয়েবপেজ
- `style.css` — ডিজাইন
- `script.js` — countdown, audio controls, browser visitor count
- `audio/dhak(1).mp3` — ঢাক
- `audio/1.mp3` — প্রথম গান
- `audio/2.mp3` — দ্বিতীয় গান

## GitHub Pages
রিপোজিটরির root-এ `index.html` রাখবে। GitHub Pages-এর publishing source হিসেবে `main` branch-এর root নির্বাচন করলে সাইট publish করা যাবে।

- `assets/puja-background.png` — তোমার দেওয়া দুর্গাপূজার background image
